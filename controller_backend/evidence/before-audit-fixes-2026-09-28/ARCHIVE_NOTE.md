# Archive note: LinuxCNC adapter evidence before the 2026-09-28 audit fixes

This directory preserves, byte-identical, the `controller_backend/evidence/` files that were current before the audit-fix pass of 28 September 2026: the real-LinuxCNC run `0544b28f-9abf-4984-8ff9-d1f61672d925` (`linuxcnc-simulation.json`, `linuxcnc-raw.log`, `linuxcnc-trace.json`; 2026-09-28T08:49:34Z, 12 passing checks, 3,167 trace samples, task main-loop maximum 0.127382 s with 10 excursions), the rootfs provenance record and package list copied by that run, and the 30-test fake-API contract log. They are archived because the fix pass changed `StatusSample.ini_filename` to carry the controller-reported INI path and changed the demo's `attached_exact_simulation_profile` check, which in these files compared the adapter's expected path with itself (a tautology; profile identity was nevertheless enforced inside `connect()`/`poll()`). The launcher was then rerun and the live files beside this directory were replaced. `demo.py.pre-fix` (sha256 2f724bff…) and `linuxcnc_backend.py.pre-fix` (d9f9d817…, CRLF line endings as found) are the sources that produced run 0544b28f. The report text previously cited an older run, `da9f1f4c-a338-494a-9e69-67787eb6c9af` (05:01:13Z, 3,166 samples, 0.123849 s), whose evidence files were already overwritten before this archive was made; only its figures in the report history remain, not its files.

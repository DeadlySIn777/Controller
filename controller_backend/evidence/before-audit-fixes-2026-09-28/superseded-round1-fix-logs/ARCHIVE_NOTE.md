# Archive note: first-round audit-fix test logs, superseded the same day

These three files are byte-identical copies of `controller_backend/evidence/backend-contract-tests.txt` (Windows Python 3.14.6, 45 tests, 3 skipped), `backend-contract-tests-linux.txt` (WSL root, Python 3.14.7, 45 tests, 2026-09-28T19:05:59Z) and `rootfs-layer-filter-check.json` (cached pinned layer through the filter, 2026-09-28T19:02:24Z, no refusal) as recorded after the first round of the 28 September 2026 audit fixes. They were archived before regeneration because a follow-up review found that the first-round `rootfs_member_filter` checked only the parent of a symlink member and so accepted a symlink named `p/..` after `p -> .`; on CPython builds without the CVE-2025-4138 link-fallback re-filter that member could chmod/chown the directory above the rootfs. The filter now refuses symlink members whose last name component is empty, `.` or `..`, extraction requires `tarfile.LinkFallbackError`, four tests were added (49 in total), and the live logs and the cached-layer check beside `before-audit-fixes-2026-09-28/` were regenerated. The LinuxCNC simulation run `bac564b6-1f50-4593-86bc-b3d496f33e75` did not depend on the fetcher and was not rerun.

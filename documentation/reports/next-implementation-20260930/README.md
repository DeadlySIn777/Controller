Independent circuit review found a further **FPGA startup/default integration blocker**: T20 GPIO have weak pull-ups during reset/configuration. The frozen 100kOhm request/progress pull-downs can leave these nodes around 2.73V, so they do not prove LOW or a disabled SET1.

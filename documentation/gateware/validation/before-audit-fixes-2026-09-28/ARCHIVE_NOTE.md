# Archive note: RTL simulation evidence before the 2026-09-28 audit fixes

This directory preserves, byte-identical, the `gateware/validation/manifest.json` recorded at 2026-09-28T06:30:23Z (default ABI v1, 180 counted checks, Icarus Verilog 13.0 and Verilator 5.048 in WSL `GarciaMechBuilder`, Alpine 3.24.2) together with every file it hashes under `files/<manifest key>`: the pre-fix RTL, testbench, vectors, codec, runner, recorder, `PROTOCOL.md`, `simulation.log` and `status_encoder.hex`. All 13 archived files match the archived manifest's SHA-256 values. It was archived because the audit-fix pass changed the RTL (two-flop synchronization of the inhibit for every clocked consumer, MISO update one tick after the detected SCLK rise, capability page consumed by rejected transactions, Verilog-2001 forms, new `progress_wdi` output), added an ABI v2 testbench and new checks, and made the recorders and `protocol.py` write LF. The live `simulation.log`, `status_encoder.hex` and `manifest.json` beside this directory were then regenerated by the documented `run_tests.sh` and `record_evidence.py` commands. The archived manifest, `vectors.hex` and `vectors.json` were written with CRLF on Windows; they are kept as found, and `gateware/.gitattributes` exempts this directory from line-ending conversion.

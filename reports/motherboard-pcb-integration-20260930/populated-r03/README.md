# r03: bounded supply-bypass placement correction

This candidate retains the corrected **880 physical / 878 fitted** source snapshot. It moves **26 new capacitors, four neighboring new resistors and four new motor-region ICs**; `bounded-placement-changes.json` is the exact reference and before/after ledger. No retained 327-part placement, source connection, footprint/pad/stencil shape, copper, filled-zone definition, rule or annotation changes. The 1,907-item original copper remains unchanged; the root's later 95-item routing delta is not included here.

All **18 new ISO1212** bypass capacitors now have center-to-VCC1-pad distances at or below **2 mm**, conservatively following the manufacturer's Figure 8-18 placement limit. All ten r02 targets that exceeded 3 mm are now closer to authentic supply pads. The maximum over all 79 measured targets is **2.951 mm**. TPS274C65 measurements select the nearest actual VS pad from its eight connected supply pads; they no longer measure an arbitrary first-numbered pad across the package.

These distances close the reported placement gaps. They do not establish qualified supply loops. The local capacitor supply and ground connections, return plane/vias, cross-domain isolation and package thermal paths remain unrouted or unverified. Independent native KiCad checks show **zero regular DRC violations, no ignored checks and 1,637 uncapped missing joins**. All **20 native population/mutation/placement tests pass**. The native review PDF/PNG was inspected, including the four moved motor-region ICs and 12 distinct DI pairs. The provisional outline remains **460 × 340 mm / six layers / 1.6 mm**.

Manufacturer-specific routing obligations:

- ISO1212: use the existing 0.1 µF VCC1 bypass close to pin 2, top-side placement and a GND1 return underneath. Figure 8-18 specifies 2 mm maximum. Keep field-side filter/current-limit parts close, maintain the specified external high-voltage spacing, and retain independently floating substrate islands. These field geometry constraints have not been closed by this capacitor revision. [TI ISO1212, sections 8.3–8.4](https://www.ti.com/lit/ds/symlink/iso1212.pdf).
- SN74LVC00A and SN74LVC2G08: place 0.1 µF close to each VCC pin with an actual ground return; unused inputs remain biased. The manufacturer does not supply a universal 3 mm acceptance rule. This revision optimizes actual supply/ground proximity and retains the required routing work. [SN74LVC00A](https://www.ti.com/lit/ds/symlink/sn74lvc00a.pdf), [SN74LVC2G08](https://www.ti.com/lit/ds/symlink/sn74lvc2g08.pdf).
- LTC6994: connect the ceramic 0.1 µF directly to V+ and GND through a low-inductance path; for TSOT-23, the manufacturer permits a ground-plane return with multiple vias when a direct top-layer return is obstructed. SET/RSET routing requires its own short, protected path. Those copper loops remain unimplemented. [ADI LTC6994, printed page 21](https://www.analog.com/media/en/technical-documentation/data-sheets/LTC6994-1-6994-2.pdf).
- TPS274C65: the local 1 µF VS capacitor remains on the actual field rail, with its own field-ground return. Section 9.4 additionally requires substantial thermal copper, thermal-via implementation, controlled solder coverage and via treatment under the exposed pad. Moving the capacitor does not satisfy these thermal/assembly requirements. [TI TPS274C65, sections 9.4.1–9.4.2](https://www.ti.com/lit/ds/symlink/tps274c65.pdf).

No module/terminal sockets, 980-source additions, field power planes, fabrication files or physical measurements are added or claimed. Root integration must preserve the exact 880 snapshot when applying its separately reviewed copper delta.

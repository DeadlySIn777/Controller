# Current controller comparison — 1 October 2026

This records the comparison requested in the user's latest attachment. It is a current engineering review, not a shipping specification or a measured performance ranking. The attachment's historical 880-footprint count and speculative 9.3/10 rating are not evidence for the present board.

The actual source26 motherboard contains 2,688 footprints: 2,642 purchased fitted parts, 44 bare PCB features and two DNPs. The completed population sanity review found no old thirteen-card rack, DIN card cage, duplicated compute SoC or duplicated ESP32 die. There are actual purchased-module sockets. Resistors, capacitors and diodes account for 2,132 footprints; the function counts and exact parts are in [the frozen source26 sanity review](../current-source26-2688-sanity-r02/review.json). Separate protection and isolation domains are not automatically redundant merely because they use the same MPN.

The current independently checked r56 PCB has 2,688 footprints, 9,818 tracks/vias, 1,507 zone objects and 3,997 missing physical joins. It has zero native DRC errors, 50 unsuppressed isolated-copper warnings and two unsuppressed FIELD_B return-track warnings, with no ignored checks. Source population, physical pin nets, all 44 floating thermal islands and the 256-pad FPGA allocation agree with the actual source. These checks do not establish complete routing, load capacity, FPGA routed timing, 20 ms measured inhibition or manufacture readiness. The native evidence is in [r56 connectivity](../../motherboard-pcb-integration-20261001/source26-entry-return-r56/independent-connectivity/review.json) and [r56 native DRC](../../motherboard-pcb-integration-20261001/source26-entry-return-r56/drc.json).

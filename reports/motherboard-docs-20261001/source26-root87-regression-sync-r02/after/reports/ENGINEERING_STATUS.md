## Corrections found during engineering

- LinuxCNC run completion cannot be treated as a quick synchronous command acknowledgment. The adapter dispatches appropriate motion commands asynchronously and observes their actual completion.
- Request deadlines are checked again after status reads and before each individual command write; a slow mode change cannot make a stale motion request execute later.
- A first ESP counter sample does not prove progress. The helper now requires a later forward change within the same observed boot. Diagnostics remain advisory because UART queue age and sender authentication are not established.
- The previous field-side small-LDO allowance could dissipate 1.25 W at the proposed maximum input. That branch needs a switching regulator. The ESP also gets a separate regulated branch. The older cost comparison is explicitly annotated with these corrections and remaining unknowns.
- The electrical study's 250 ksteps/s goal is not achieved by the current reference RTL. Its tested configured cap is 195,312.5 steps/s at an assumed 50 MHz clock. Raising that cap alone cannot reach the goal: with the 100/100-tick STEP high/low defaults the minimum fault-free STEP period is 201 core ticks, a ceiling of 248,756 steps/s, and the RTL testbench shows that a 250 ksteps/s rate increment latches a timing fault ([gateware validation](GATEWARE_VALIDATION.md)). Physical rate capability remains unqualified.
- Power budgets currently warn about less than 20% headroom on two proposed rails. Numerical reservations and regulator capacity still need optimization and measurements.
- Integration review added host-age and implausible-counter checks, coherent encoder/index wrap handling and configuration freezing. The new controlled exception permits step-scale changes through a stopped acquire/commit/release transaction, with active HAL scale pins read-only and actual joints unhomed. Encoder scale and channel mask retain mutation-fault behavior. The compiled reference still uses a simple digital pulse-count correction loop, not a qualified physical servo design.

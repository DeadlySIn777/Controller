Prospective bound partition tools: SOURCE ONLY / NOT RUN

native_bound_partitions.py explicitly loads the sibling project through the
native settings manager, loads the board, captures class/global/effective
state, calls BOARD.SetProject with that exact handle, and requires unchanged
effective state. The source checks compare declared netclass dimensions and
global dimensional rules with the exact project JSON. It preserves the old
uncapped pad partition naming, traversal and count semantics. The intended
native sequence is Fill followed by BuildConnectivity; no board or project
save is requested, and cleanup unloads without saving.

prepare_bound_run.py creates a distinct exact project/source clone and captures
all original source, clone, effective footprint-library, tool and native binary
identities. It defaults to preparation only; --run starts a single selected
existing KiCad slot and verifies every identity and saved manifest afterwards.
No invocation of either native path or preparation clone has been made here.
The tools are held for root review, not deployed into any shared or frozen run.

board/project effective-class disagreements are refused; authentic model state
passes; repeated pad numbers retain the exact old #k IDs; connected and split
model pads retain old uncapped count semantics. Python source compilation also
passes. These do not establish that the native SWIG producer executes correctly.

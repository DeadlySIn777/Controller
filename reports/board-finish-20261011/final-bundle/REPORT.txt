Staged final experimental ROOT106 evidence + editable native bundle runner
===========================================================================

qualify_bundle.py is source-only. It starts no KiCad/native/GPU work, saves no
board, changes no live or adopted sources, and writes only a NEW child folder
below final-bundle after all read-only qualification gates pass.

Required inputs: explicitly selected candidate+SHA, completed measurement,
same-SHA API parity, and actual fresh schematic export. It independently checks
the strict 40f8 r06 partition/API guard and raw all-severity DRC=0, every pinned
measurement proof observation/construction input, native API report contents,
exact frozen 27-sheet source hierarchy, and fresh semantic component/net/node
export equality. Warnings and uncapped incomplete joins remain visible.
Effective project binding now requires the explicit PASS audit, native raw
probe validation, official 10.0.4 CPP snapshots, native version/runtime hashes,
and exact measured sibling project/rules hashes. Audit pin11d1f30e verifies
implicit LoadBoard settings equal explicit binding, so no observed binding
difference requires a new refill. This remains bounded evidence: silent rule
initialization catches exist and full compiled-rule/every-condition equivalence
is not exposed by the API. The final same-version completed raw DRC report and
no CLI rule-parse-failure diagnostics remain mandatory gates. Netlist-only API
project binding alone does not satisfy these requirements.

The bundle's native/motherboard.kicad_pcb is byte-exact and editable, as are
motherboard.kicad_pro/.dru and the 27-sheet source hierarchy. This is an explicit
basename alias of measured board.* settings; actual native-open qualification
of that alias is not established by copying. Immutable original board, measured
settings, source and receipts are retained under evidence. A complete manifest
records each copy's original path and SHA. CAD30 is kept separate.

fp-lib-table remains exact. Its local resources are copied into native, and all
absolute effective URI resources are archived without rewriting those URIs.
The exact sym-lib-table points at 27 real libraries found in saved ERC source,
but 10 embedded definition mismatches remain (380 embedded symbols vs 372
external symbols). Matching original libraries become effective; mismatched
libraries are preserved under resources/original-symbols and remain absent at
the table's effective URI. No schematic definition is replaced or fabricated.
Source/API parity uses the genuine embedded schematic definitions. Symbol
library reload/native export after resource copying has NOT run.

No fresh stored fills are claimed. Native proofs refill in memory, while exact
candidate bytes retain stale cached source fills. Refill/save changes SHA and
requires new qualification. Open matrix preserves routing, ERC3171 warnings,
SI/power/returns/isolation, field-current maxima, limited DFM, thermal/fault and
physical/manufacturing gaps. Historical verify counts are labelled prior
cc05353 evidence, not candidate measurements. No fabrication exports exist.

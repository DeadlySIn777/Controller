## Hardware/software integration and ownership

The recorded working allocation is Codex for schematics, power/protection, connectors, PCB and BOM; Claude for FPGA logic, CNC1 protocol/driver and configuration-service integration. It binds channel/port identities, enable/alarm polarities, framing, card identity, power/reset/watchdog behavior, telemetry validity/age, timing and recovery. It is not integrated into the main checkout or implemented as complete RTL/HAL/hardware. Preserve that frozen revision unchanged as source history; IS-2 supersedes its passive-base/card/MX4 physical allocation and requires reviewed integration of retained logical/electrical/fault contracts; do not silently edit it or treat the older 128-byte expansion draft as its actual 176-byte feedback/96-byte command ABI.

An actual Git baseline exists: `e994311` (28 September 2026). Later commits `80cc958`, `c61ccbf` and `477c225` record product/commercial decisions. A separate committed worktree therefore exists; controlled integration into main and agreement that both drawn hardware and executable software meet the retained IS-1 contracts plus versioned IS-2 physical/identity transition remain open. Preserve the baseline and user changes; interface changes require explicit versioning and independently reviewed merge evidence. This audit creates no production firmware, bitstream or physical interface approval.

# Actual compute Ethernet and independent communications source — r05

The compute region now fits 191 physical footprints: 183 purchased parts and eight bare PCB test pads. It adds 49 physical parts to the frozen142 subset. Both retained100-contact sockets remain the purchased-module bay; no duplicate processor or PHY is fitted. Native KiCad ERC has zero errors and warnings, independent complete930-pin/276-net checks pass, and54 disconnected destructive-mutation tests pass. These checks are source evidence only.

Eight previously NC compute contacts are promoted through the bounded native rename ledger:25/26/27/28/29/31/50/51. All other142 retained physical pins/MPNs/footprints are unchanged. GPIO14/contact55 remains the read-only ESP service TX. The exact canonical compute-health observation is `COMPUTE_3V3_GOOD`: U15002 pin4 from the actual module-own auxiliary supervisor, B15003.5 and B15012.9. It is neither an OS identity nor an OS-ready flag.

UART uses TX GPIO12/contact31, RX GPIO13/contact28 and RTS/DE GPIO15/contact51. The official Linux sources use uart5 on CM4 and uart4-pi5 on CM5. A custom TX/RX/RTS-only pin group is required because the ordinary CTS/RTS group also claims the retained GPIO14 service pin. CAN uses its own SPI1 GPIO19/20/21, GPIO16 chip select and GPIO17 interrupt. These are physical pin candidates; target device trees/drivers/baud/deadlines are uncompiled and unqualified. The FPGA motion SPI0 transport remains separate.

U15032 inverts actual compute3V3 health to a default-HIGH disable net. Five forward SN74LVC1G125DBVR buffers are powered by IO3; three return buffers use the module-own auxiliary rail. Every direction has actual default bias,100nF bypass and33ohm source damping. Driver enable defaults LOW. The frontend must also protect any power-cycled controller output from the carrier's HIGH interrupt bias; an independent review identified and reported the actual MCP interrupt injection path for correction by its source owner.

J15007 is purchased Würth7499111446. Its manufacturer revision003.000 pages1–3 supplies the exact14 contacts, two shell stakes, two locating posts, four1:1 transformers, internal line-side termination and −40..85°C component range. Pin1 is the common PHY centre tap, AC-returned through100nF to LOGIC_GND. Pin10 and shell stakes use CHASSIS. Pin10 is the internal line-side Bob Smith capacitor return, not a PHY ground pin. Two TPD4EUSB30DQAR arrays reference the PHY-side LOGIC_GND as in Raspberry Pi's CM5 reference. The purchased module already contains the PHY; no extra PHY or PoE circuitry is invented. The two anti-parallel jack LEDs are wired for active-low green operation, with470ohm actual series resistors. This does not prove link, Ethernet compliance or industrial board operation.

The exact-part native Würth footprint was checked against the manufacturer hole pattern; its four LED drills are corrected from1.02mm to the current drawing's1.03mm. No unverified3D solid is substituted. Final panel cutout, shell/panel bond, clearances,100ohm differential routing, pair matching, ESD return/EMC and loaded link behavior remain to be implemented and measured on the parent PCB. The isolated schematic render was inspected in Ethernet, communications and passive regions.

The auxiliary3V3 reservation increases from0.425A to0.447A for the actual new interfaces. This is a planning allocation, not a maximum-load qualification. BTT mappings, PHY bias, auxiliary-current guarantees, boot images and transport remain separately unqualified. OptionalNVMe remains an explicit unfinished electrical/mechanical boundary; SD/eMMC do not depend on an SSD. The complete controller is not manufacture-ready.

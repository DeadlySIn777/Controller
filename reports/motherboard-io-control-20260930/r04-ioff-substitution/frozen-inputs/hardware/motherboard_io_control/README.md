# Soldered IOL1 acquisition and control nodes

Source candidate r0.3, 30 September 2026: **100 physical footprints / 342 electrical pads**, comprising 82 purchased assembly parts and 18 bare PCB factory test pads. Three STM32G031 MCUs are soldered regions of the single active motherboard: L0 DIC uses STM32G031C8T6 / LQFP48 to acquire 24 DI; L1 DOA and L2 DOB each use STM32G031K8T6 / LQFP32 to control eight DO. These retain the three frozen IOL1 lanes, class/slot checks and independent failure domains. They add no removable custom card, rack connector or MCU module.

The native schematic, XML netlist, BOM, model, boundary map and independent validation agree. Native KiCad ERC has zero errors, zero warnings and no ignored checks. ST DS12992 package pin columns and alternate functions were independently checked: each SPI1 slave uses PA4–7; each DO SPI2 master uses PB8 / PB7 / PB6 with PB9 software chip select. Actual host nets are IOL1_Ln_CS_N, IOL1_Ln_SCLK, IOL1_Ln_MOSI and IOL1_Ln_MISO, through real Ioff buffers and 22 Ω source damping. Loaded roundtrip timing remains unmeasured.

All 24 general inputs connect to the actual DI0_LOGIC through DI23_LOGIC frontends. Five active HIGH DI sensor/safety fault observations have pull-ups, so missing parent monitors read fault or unavailable. Each DO MCU observes actual OUT_PERMIT, OUT_EN latch Q, DO_EN and isolated FLT; its field-power-good input has a pull-down. The protected sensor limiters and isolated field-power monitors remain parent circuit work. The existing 0.20 A per DI supply group, 0.5 A per DO channel and 2 A per DO quad limits remain unchanged.

Each MCU has its own TPS3808G33 rail supervisor, a nominal 3.07 V threshold and open CT for a nominal 20 ms reset-release delay. Separate local NRST nets preserve independent node reset. Each DO NRST drives a SN74LVC1G17 buffer into the frontend reset input. This avoids a 1.65 V divider between the MCU NRST pull-up and frontend reset pull-down. The DO frontend already owns the CARD_EN/STROBE pull-downs; only four duplicate 13xxx resistors were removed. See the dated population-change record for exact references. Three obsolete bulk capacitor MPNs were separately replaced with manufacturer-verified GRM21BR71A475KE51K, preserving value, nets, footprint and population.

The candidate hardware-started IWDG setting PR=/4, RLR=9 counts 40 independent LSI clocks: 1.176–1.356 ms across 29.5–34 kHz. This checks the count period; it does not prove complete reset and field inhibition within 2 ms. Required options include IWDG_SW=0, NRST_MODE=3 and IRHEN=1. Firmware must configure and verify them before asserting CARD_EN, validate complete 40-byte IOL1 frames before outputs or watchdog refresh, enforce the 1 ms accepted-frame timeout, verify zero outputs and the 0.72 A commissioning limit before enable, and require a new epoch/IO_ENABLE after loss or reset. The driver's 1.25 A POR limit is a different state. DIC VREFBUF must remain disabled because VREF+ is externally supplied by IO_3V3.

**Target firmware, option programming/readback, protected bootloader, factory identity/calibration record and loaded operation are not implemented.** The MCU UID does not replace the manufacturing record. IO_3V3 budgeting must include enabled peripheral clocks, GPIO loads and buffers; the 6.9 mA maximum 64 MHz/85 °C core figure excludes peripherals. Final PCB routing, return paths, assembly testing and physical fault/timing qualification remain open. This region creates no fabrication files and establishes no firmware qualification.

Factory test pads are PCB copper and must be excluded from purchased-parts BOM and SMT placement processing. See reports/motherboard-io-control-20260930/receipt.json for the exact frozen inputs and validation evidence.

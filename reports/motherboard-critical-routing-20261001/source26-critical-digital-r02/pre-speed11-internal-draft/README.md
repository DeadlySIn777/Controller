# Source26 critical digital route review

This is an exact source and placement review for 29 groups, 154 native nets and 482 physical endpoints. It preserves the ordinary112 eligibility list and every electrical source file. It is not a motherboard autorouter allowlist, routed-path receipt, device timing signoff or manufacturing release.

`critical-digital-source-review.json` gives the actual full physical pin inventory and return domain for every net, actual resistor identities, 79 driver/receiver pad-distance lower bounds, the existing PCB connectivity clusters and prospective per-side references. The source is adopted source26; the inspected board is the immutable r50 board. There are 202 independently counted missing joins within this selected scope; 38 of the 154 nets are fully joined. All 10 independent source/domain/timing negative controls and three real native joined/unrouted/cut copper controls pass.

## Actual topology

* IOL1 is four separate point-to-point lanes. Each lane has a real Nexperia74LVC125APW,118 quad buffer and four22Ω source resistors. DIC/ACC use MCU SPI1 pins15/16/17/18; DOA/DOB use11/12/13/14. The zero-ohm PB5 counter taps are after the MCU-side clock source resistor, on physical pin44(C8T6) or29(K8T6). These taps are additional local receiver loads. They are not new FPGA lanes,33Ω resistors or a shared four-node bus.
* HostSPI uses the actual five qualified1G125 buffers and33Ω resistors. Forward buffers use IO3; the MISO return buffer uses the compute module's actual auxiliary3.3V. Its real hardware OE qualifies module rail, FPGA reset release and CDONE. The exact CM4/CM5 GPIO/profile output timing remains a target constraint; supported BTT profiles are not inferred.
* ACC SPI2 physically shares clock and MOSI among three ISO7761 inputs. Separate CS lines control three real CS-gated1G125 MISO returns. It is not three independent single-load clock lines. ADC SDI is physical pin1 and SDO36; the native source already maps these correctly. The two DACs are exact readback-capableAD5683RBRMZ-3. The host and each of AI_AGND/AO0_COM/AO1_COM must retain separate own-domain references; copper never crosses the isolation barrier.
* DOA and DOB each use a real ISO7762 and two addressed TPS274C65AS devices on shared CS/SCLK/SDI/SDO. Hardware permission remains independent and LOW in the diagnostic target. Each bank's field return is explicitly different. The frame inactivity minimum is500ns; address/CRC/readback semantics remain target requirements.
* Configuration/flash, the50MHz oscillator, supervised resets and real permission/latch/strobe chains are included separately. The ADC precision reference/capacitor cell and analog terminal/current loops remain outside this digital selection.

## Real timing conditions

`primary-timing-facts.json` records primary conditions instead of treating a headline MHz rating as a board limit. Exact retained primary PDFs are hashed in the source review. Official ST and ADI PDFs were read through the web tool; direct downloads timed out and are not claimed retained locally.

The current IOL1 diagnostic target uses fixed six50MHz cycles per SCLK period:8.333MHz,20µs CS setup,5µs hold and40-byte frames. There is no implemented lower-frequency profile in that target. The code sets GPIO alternate functions but never sets OSPEEDR. It therefore retains speed00. ST's12ns SPI output-valid limit and32MHz full-duplex rating require speed11 and30pF. Current speed00's2–3MHz output capability and75–100ns transition limits do not validate the present8.333MHz target or4MHz DO SPI2. This is a real firmware qualification gap; this review does not alter the firmware.

Even after a reviewed speed setting, the4.8ns Nexperia buffer limit requires input transitions≤2.5ns and its stated50pF output load. ST speed11 at30pF gives5.5ns maximum transitions; speed11 at10pF gives2.5ns. MCU/receiver input capacitances are typical values with no guaranteed maximum in the reviewed tables. A union of the two headline delay limits therefore needs actual load/edge verification. The conditional IOL1 half-cycle budget is60−12−2×4.8=38.4ns, before route flight, FPGA input setup/output delay, skew, jitter and settling. That arithmetic is not a current acceptance result.

DO's equal3.3V isolation profile can use the actual ISO776x table only with the stated15pF output load and supply/edge conditions. The conditional4MHz return budget is125−2×18.5−30−1=57ns before route effects. AO/AI use actual mixed3.3/5V isolation rails; their equal-rail tables do not guarantee mixed-rail maximum delays. The DAC readback's35ns data-valid limit, real return buffers and chip-select handover must be included. ADS8684A's reviewed timing table uses DVDD3V while the source uses5V; the actual read mode/pipeline/rail condition needs qualification. The current ACC diagnostic firmware reports the ADC/DAC readback unavailable while hardware RESET is asserted, and does not implement ACC SPI2 transactions.

The50MHz oscillator specifies15pF output load and4ns maximum rise/fall, with no minimum edge bound. T20 active configurationDIV4 is14–26MHz, DIV8 is7–13MHz; the actual boot header selection is unproved. Winbond's standard03h50MHz limit is distinct from faster opcodes. FPGA user GPIO STA, package fit, loaded firmware and physical waveforms remain separate evidence.

## Concrete route constraints

Actual HostSPI resistor-to-FPGA straight pad spans reach389.519mm and the ACC IOL1 link approaches294.357mm. The shared analog clock fanout spans the AI and AO regions. These are transmission-line candidates. Reducing clock frequency does not slow a driver's edges. No150mm limit, generic trace capacitance/flight velocity or guaranteed lumped30pF load is invented.

The reusable exact-net proposal is in `route-configuration-proposal.json`. It requires the full native pin inventory, correct rail/return, continuous adjacent F/In1 or B/In4 own-domain reference and real flashed/source-connected return stitches within1mm at a layer transition. Primary source-resistor values and local tap ownership are immutable. The long clock/data lines have an engineering50Ω±10% target; actual widths/gaps require the manufacturer stackup/field solver and remain null here. This target is an engineering selection, not a manufacturer mandate.

Keep driver-to-series-resistor stubs local. The report screens5mm as an engineering target only:19 of23 existing straight-distance lower bounds exceed it, including R1002 at24.586mm and Host MISO R15018 at18.858mm. These are actionable placement/line-model review items, not19 manufacturer-rule failures. Clock/count tap branches require actual route-length/flight and receiver-edge review. No arbitrary certified5mm PB5 limit is asserted. Long-line loading must use the routed line model, actual pad/package loads and driver IBIS/measurement; typical Cin and a guessedpF/mm do not close the load budget.

Before execution, bind the exact final PCB and passed plane receipt, review the actual conductor widths/reference geometry and check source resistor/tap topology. After routing, measure the actual paths/stubs, check exact widths and own return corridors, preserve every old native source/pad/copper identity, run native DRC and independently count missing joins. A routed prototype can carry explicitly conditional physical timing/EMC qualification; it cannot be labelled as proving the8.333MHz loaded target from these source tables.
